MicroPythonRaspberry Pi PicoFlaskADCSerial (USB)SSEPythonMatplotlib

Personal Project · Embedded Systems

A complete embedded systems pipeline built from physical hardware to a live web dashboard. The Raspberry Pi Pico reads three simultaneous channels — internal chip temperature, potentiometer position (0–100%), and USB supply voltage (~3.3V) — at a fixed 2 Hz sampling rate using its onboard ADC. Data is streamed over USB serial to a PC running a Flask server, which pushes live updates to any browser on the local network using Server-Sent Events (SSE), with no page refresh required.

The project spans six purpose-built files: firmware on the Pico, a web server, a CSV data logger, a cross-correlation analyser, a live Matplotlib graph, and a one-click batch launcher. Plugging in the Pico and double-clicking launch_daq.bat brings the full system online in seconds — a real-time dashboard visible to every device on the WiFi.
